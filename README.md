# learning-log

> 学习记录仓库：把学过的东西写成能回看的笔记，而不是收藏了就算学过。

## 简介

这里记录我系统学习某个主题时的过程：看了什么、想通了什么、还卡在哪。重点是留下思考的痕迹，方便日后快速捡起来。

## 目录结构

| 目录 / 文件 | 说明 |
| --- | --- |
| `topics/` | 按主题分目录，一个主题一个文件夹 |
| `topics/<主题>/README.md` | 该主题的总览与学习路线 |
| `inbox/` | 还没归类的零散想法，定期整理进 `topics/` |
| `reviews/` | 周期性复盘，记录哪些学扎实了、哪些还要补 |

## 记录格式

每篇笔记统一按三段写：

1. **一句话结论** —— 这个东西解决了什么问题
2. **核心内容** —— 用自己的话讲清楚，配最小可运行的例子
3. **遗留问题** —— 还没搞懂的地方，写下下一步查什么

## 使用原则

- 看懂不算学会，能讲给别人听才算
- 优先写最小例子，跑通了再扩展
- 卡住超过 30 分钟就记录下来，换个时间再看，别硬耗
